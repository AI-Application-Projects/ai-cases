# 现状审计

## 页面与数据来源

- `index.html` 展示招投标评审样例。
- `main.js` 硬编码决策、风险数量和风险清单。
- `poc/outputs/sample-output.json` 是脱敏样例产物，未关联 Dify Run ID。

## DSL 与数据资产

- Prompts、Schema、招标/方案样例、报告样例均存在。
- JSON Schema 覆盖项目、强制条款、评分项、缺口、建议和人工复核队列。
- 草稿 DSL 使用 `prompt_file` 等非 Dify 导出字段，无法作为可导入 DSL 验收。

## 阻塞项

1. 缺少经 Dify 1.16.1 导出格式验证的 DSL。
2. 缺少可用模型配置与测试用应用 API Key。
3. 缺少真实运行快照、Run ID、节点状态、耗时和失败记录。
